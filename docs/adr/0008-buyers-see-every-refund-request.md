# Buyers see every Refund Request, and are emailed each decision

On Settings, the Buyer sees all their Refund Requests: Open ones, and decided ones with their status and any decline note. Each decision also sends an email: approval, with the optional note, or decline, with the required note. Until a mail service is connected, these emails go to the server log.

## Considered Options

- **One line per Purchase showing only its latest refund state.** This came up during scenario testing. It was rejected in favour of showing every request, so a Buyer can see why earlier requests were declined.
