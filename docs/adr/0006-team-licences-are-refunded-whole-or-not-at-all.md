# Team Licences are refunded whole or not at all

A Team Licence is one Purchase covering several Seats, and a Refund is always the full amount paid. So a Team Licence with any Claimed Seat can never be refunded, and there are no per-Seat refunds. The Team Admin raises the Refund Request from the team page, next to the licence. Approving it voids every unclaimed Seat so none can be claimed afterwards. The watched-hours and lessons rules don't apply, because the Buyer's own viewing says nothing about the Seats.

## Considered Options

- **Partial refunds for unclaimed Seats.** Rejected: it breaks the rule that a Refund is always the full amount, and brings in amounts the glossary doesn't have.
- **Reject requests on any Purchase that has Seats.** This was considered as a smaller first version. It was rejected because Team Admins need some way back within the 14 days.
